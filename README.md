# Bobik 3D

[English README](README.en.md) · [Цели и открытые вопросы](docs/idea.md) · [Инструкции агентам](AGENTS.md)

Bobik 3D — браузерная игра в жанре тамагочи с 3D-сценой собаки, прогрессом игрока, таблицей лидеров и аккаунтами через Supabase. Это **описание доступных исходников**, а не подтверждение развернутой или принятой production-версии.

## Проверенное состояние

Сверено 14.10.2026 с веткой `main` на исходном commit `e0fede2eff6b43076a2954aa425750475e49d3a1`. Проверены README, `package.json`, корневая структура и `vercel.json`. Сборка, миграции, браузерные сценарии и внешние интеграции не запускались; релиз и клиентская приёмка не подтверждены.

## Стек и расположение кода

- React 18, Vite 5, React Router 6;
- Three.js, `@react-three/fiber`;
- `@supabase/supabase-js` для авторизации и данных;
- `src/` — приложение и 3D-сцена;
- `api/` — серверные функции, в том числе Telegram и cron;
- `supabase/` — конфигурация и миграции;
- `scripts/` — вспомогательные проверки.

## Локальный запуск

Нужны Node.js 18+, npm и настроенный тестовый проект Supabase. По исходному README:

```bash
npm install
cp .env.example .env.local
npm run dev
```

Локальный `.env.local` заполняют значениями для выбранного окружения, не фиксируя ключи в Git. SQL-миграции в `supabase/migrations/` применяют только к предварительно проверенной базе; здесь они не запускались.

Команды, определённые в `package.json` (результаты выполнения **не проверены**):

```bash
npm run lint
npm run build
npm run smoke:auth
npm run preview
```

`smoke:auth` запускайте только после проверки целевого окружения и побочных эффектов. В проверенном корне нет каталога `.github/workflows`; `vercel.json` содержит rewrites и cron, но наличие production-деплоя этим не подтверждается.
