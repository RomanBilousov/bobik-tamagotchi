# Bobik Tamagotchi

Будущий проект про Тамагочи с Бобиком в главной роли.

## Статус

Проект только создаётся. Здесь появятся:

- игровая логика
- состояние питомца
- интерфейс
- сохранения и прогресс

## Идея

`Bobik Tamagotchi` — это заготовка под игру, в которой нужно заботиться о виртуальном питомце, следить за его состоянием и развивать его со временем.
