# Инструкции агентам — Bobik 3D

Перед изменениями прочитайте `README.md`, `README.en.md`, `docs/idea.md`, относящиеся к задаче исходники, конфигурацию и открытые PR.

- Пишите документацию, коммиты и описания PR на русском, сохраняя технические идентификаторы и Conventional Commits. Не удаляйте английский README: это версия для внешней аудитории.
- Отделяйте идеи, согласованные требования, открытые PR, объединённый код, запуск тестов и подтверждённый выпуск.
- Идеи фиксируйте со статусом; существенные решения — с датой, статусом «предложено/принято/отклонено», причиной и проверяемым источником. Не создавайте пустые документы.
- Документацию, затронутую смысловым изменением, обновляйте в том же PR.
- GitHub Projects — единственный рабочий трекер; проверяйте реальный Project и переиспользуйте существующие задачи, не создавая дубли.
- Сверяйте базовую ветку, актуальный исходный SHA, CI и условия выпуска; не считать наличие `vercel.json` подтверждением выпуска.
- Все изменения доставляйте в безопасной рабочей ветке через PR. **Merge выполняет Роман.** Не делайте прямой push в базовую ветку, force-push, auto-merge и deploy.
- Не меняйте код, зависимости, workflow, права или конфигурацию выпуска ради правок документации.
- Не коммитьте токены, значения переменных окружения, секреты администрирования и персональные данные. Миграции, cron и smoke-тесты могут затронуть внешние данные: без проверки среды не запускать.
